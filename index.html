How does this work?

Some PDF exporters (notably Google Docs/Slides) draw highlighter rectangles that reference an ExtGState resource (via the /Name gs operator) intended to blend the highlight color using Multiply mode — which is what lets black text show through a light-colored highlight. However, the exporter sometimes forgets to actually define that ExtGState resource in the page. Viewers then fall back to fully opaque rendering, producing solid yellow (or other colored) bands that hide the text underneath.

This tool scans every page's content stream for gs operators referencing undefined ExtGState resources and adds the missing definitions (Multiply blend mode, or the explicit alpha value encoded in the resource name, e.g. pgf@ca0.30). It never touches or removes any text or drawing content, so nothing becomes unselectable.
